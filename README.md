# KC Macro & Cross-Asset Terminal

Suite de análisis macroeconómico, balance direccional de activos cruzados (Pros ▲ vs. Contras ▼), spreads de crédito corporativo ICE BofA OAS y matriz de decisión táctica (LONG / HOLD / SHORT).

## 📊 Características de la Terminal

* **Ultra Ligera y Rápida:** Construida en Vanilla HTML5, CSS y JavaScript moderno sin dependencias pesadas.
* **Balance Direccional Estructurado:** Conteo neto de argumentos alcistas y bajistas con tope anti-ruido de 4 factores.
* **Matriz de Decisión Táctica:** Posturas de mercado (LONG, HOLD, SHORT) cruzadas con niveles técnicos y gatillos de invalidación.
* **Radar de Datos Macro EE.UU.:** Seguimiento de NFP, CPI, PPI, PCE, PMI y FOMC con matriz de 3 escenarios pre-dato ("Qué pasa si...").
* **Gráficos TradingView en Vivo:** Cobertura de 8 activos guía cross-asset (SPX, QQQ, US10Y, DXY, Oro, WTI, MOVE, RSP) y 4 spreads de crédito OAS.
* **Hilo Conductor & Bitácora Histórica:** Registro de cambios diarios de régimen y correlaciones dominantes.
